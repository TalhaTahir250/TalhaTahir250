### [Global Weather Forecasting](https://github.com/TalhaTahir250/global-weather-forecasting)
End-to-end forecasting and analytics across 134,878 observations from 211 countries. Includes Ridge, XGBoost and Prophet, Isolation Forest anomaly detection, SHAP analysis and MLflow tracking. The repository reports an XGBoost MAE of 1.503°C and R² of 0.959.

**Stack:** Python · Pandas · scikit-learn · XGBoost · Prophet · SHAP · MLflow

### [Bike Demand Forecasting System](https://github.com/TalhaTahir250/bike-demand-forecast-system)
A next-day demand forecasting service with time-aware feature engineering, Optuna-tuned Ridge regression, walk-forward validation and a FastAPI inference endpoint. Includes Docker and GitHub Actions workflows, with AWS ECS deployment documented in the project.

**Stack:** Python · scikit-learn · Optuna · FastAPI · Docker · GitHub Actions · AWS

### [Telco Churn Prediction](https://github.com/TalhaTahir250/telco-churn-prediction)
An XGBoost churn-risk pipeline with class-imbalance handling, threshold tuning, MLflow experiment tracking and a FastAPI prediction service. The project reports 97.3% recall.

**Stack:** Python · XGBoost · scikit-learn · Optuna · MLflow · FastAPI · Docker

### [Spotter Freight Rate Prediction](https://github.com/TalhaTahir250/spotter-freight-rate-ml-assessment)
A freight-rate modelling assessment featuring chronological validation, rolling backtests, feature engineering, Ridge regularization and automated tests. The repository reports a mean MAE of $150.49 across July–October 2025 rolling holdouts.

**Stack:** Python · Pandas · scikit-learn · Ridge Regression · unittest
